# Provider catalog <Tag description={"v26.4+"} />

Find provider implementations that connect Kubling to external systems. Search
by product or technology, or narrow the catalog by category, provider type,
advertised capability and distribution channel.

<Callout type="info">
  Every provider currently listed is developed and released by the Kubling
  project. **Official** identifies that ownership; **Integration** connects a
  production source, while **Reference** is intended for development and
  compatibility testing. The **Available as** labels link to the currently
  published container or package channel. Use the source link to review
  compatibility notes before upgrading.
</Callout>

The capability badges describe optional provider-side support. A missing badge
means that the provider does not advertise that optional contract, or that
Kubling keeps the work in the engine where applicable. It does not mean the
provider cannot execute ordinary catalog, query or mutation operations.

For versioning, compatibility and contribution guidance, see the
[Provider overview](/providers#releases-and-compatibility).
