# Quickstart

Choose a path based on what you want to keep after the first run. Both paths
start Kubling with working providers and give you a complete environment to
query.

<Callout type="info">
  If you are evaluating Kubling for the first time, start with the maintained
  sample. Use KDV when you are ready to create a project of your own.
</Callout>

<Cards num={2}>
  <Cards.Card title="Run the sample" href="/quickstart/sample" arrow>
    Clone a maintained, disposable Docker Compose environment and start
    querying Kubling.
  </Cards.Card>
  <Cards.Card title="Create a project with KDV" href="/cli/first-project" arrow>
    Generate an editable project with pinned tooling, tests and deployment
    inputs.
  </Cards.Card>
</Cards>

The sample is maintained in `kubling-samples` and follows the current public
images. It is the shortest path to Studio, federation, queries and mutations.

A KDV project is intended to become part of your own source tree. Choose it
when you need to change configuration, develop Modules, run project-owned
tests or prepare a deployment.
