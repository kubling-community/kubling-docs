# Semantic modeling moved

<Callout type="info">
  Semantic federation is a product-level Preview capability. It is not tied to
  one runtime implementation, but its initial design is closely connected to
  the structured information Kubling exchanges with capability runtimes. Start
  with the [Semantics overview](/semantics).
</Callout>

DDL `ANNOTATION` and relationship options remain catalog metadata where they are
supported. They are not a substitute for a versioned semantic fragment,
alignment and VDB composition, and physical keys do not create semantic
relationships automatically.

For the current model and migration boundary, see:

- [Modeling semantics](/semantics/modeling)
- [Modules and configuration](/semantics/modules)
- [Logical Query v1](/semantics/logical-query)
