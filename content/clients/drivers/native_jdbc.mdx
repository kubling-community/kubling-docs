# Java JDBC driver

The Kubling JDBC driver is the recommended client for Java applications that
require JDBC. It connects through the Engine's `nativeProtocol` transport and
supports standard JDBC connections, statements, result sets, metadata and
transactions.

<Callout type="info">
  New non-Java applications should use the [gRPC client
  interface](/clients/grpc). The PostgreSQL wire protocol is a compatibility
  option for existing clients and tools.
</Callout>

The driver is open source in the
[Kubling Core repository](https://github.com/kubling-community/kubling-core)
and published with the other
[Kubling Core releases](https://github.com/kubling-community/kubling-core/releases).

## Install the driver

```xml copy
<dependency>
    <groupId>com.kubling</groupId>
    <artifactId>kubling-client</artifactId>
    <version>26.2</version>
</dependency>
```

## Connect

The driver class is `com.kubling.jdbc.KublingDriver`. The dependency registers
it with `DriverManager` automatically.

Connection URL:
```
jdbc:kubling:<vdb-name>[@mm[s]://<host>:<port>][;prop-name=prop-value]*
```

- `<vdb-name>` is the VDB to connect to. It can include the version, for
  example `myvdb.2`, or the version can be supplied with the `version`
  property. Do not use both forms in the same URL.

- `mm` selects the native protocol and `mms` selects its TLS variant.

- `<host>` is the Kubling address. Place an IPv6 address in square brackets,
  for example `[::1]`.

- `<port>` is the configured native transport port.

- Additional properties use `name=value` pairs separated by semicolons.
  URL-encode values that contain reserved characters.

## Connection Properties

| Property Name               |   Type    | Description                                                                                                                                                                                                                                                                                                                                                                                                                                        |
|:----------------------------|:---------:|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `ApplicationName`           | `string`  | Name of the client application; allows the administrator to identify the connections                                                                                                                                                                                                                                                                                                                                                               |
| `FetchSize`                 |   `int`   | Size of the `resultset`; The default size if `500`. `0` indicates that the default should be used.                                                                                                                                                                                                                                                                                                                                                 |
| `partialResultsMode`        | `boolean` | Enable/disable partial results mode. Default `false`                                                                                                                                                                                                                                                                                                                                                                                               |
| `user`                      | `string`  | User name                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `password`                  | `string`  | User credential                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `version`                   | `integer` | VDB version                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `resultSetCacheMode`        | `boolean` | `ResultSet` caching is turned on/off. Default `false`.                                                                                                                                                                                                                                                                                                                                                                                             |
| `queryTimeout`              | `integer` | Query timeout in seconds. Must be >= `0`, while `0` indicates no timeout. Can be overridden by `Statement.setQueryTimeout`. Default `0`.                                                                                                                                                                                                                                                                                                           |
| `encryptRequests`           | `boolean` | Only applies to non-SSL socket connections. When `true`, request messages and their payloads are encrypted using the connection cryptor. Default `false`.                                                                                                                                                                                                                                                                                            |
| `disableResultSetFetchSize` | `boolean` | In some situations, the client may choose undesirable fetch sizes for processing results. Set to `true` to disable honoring `ResultSet.setFetchSize`. Default `false`.                                                                                                                                                                                                                                                                             |
| `loginTimeout`              | `integer` | The login timeout in seconds. Must be >= `0`, while `0` indicates no specific timeout, but other timeouts may apply. If a connection cannot be created in approximately the `timeout` number of seconds, connection attempt will fail and the session closed by Kubling. A default value `0` does not mean that the login will wait indefinitely, instead it is up the Session Manager to close the sessions when in login (authentication) phase. |
| `reportAsViews`             | `boolean` | Indicates whether `DatabaseMetaData` must report views as `VIEW` table type. If `false` then views will be reported as `TABLE`. Default `true`.                                                                                                                                                                                                                                                                                                    |
| `connectionPropsFilePath`   | `string`  | Path to the **client** connection properties file, also known as client settings. These properties are related to networking and transport, so please do not confuse with connection string (URL) properties listed in this table.                                                                                                                                                                                                                 |

## Create a Connection
```java copy
import java.sql.Connection;
import java.sql.DriverManager;
import java.util.Properties;

var props = new Properties();
props.setProperty("user", "sa");
props.setProperty("password", "mypass");

try (Connection connection = DriverManager.getConnection(
        "jdbc:kubling:EmptyVDB@mm://localhost:35482",
        props)) {
    connection.setAutoCommit(true);
    // Execute JDBC operations.
}
```

### Client networking properties file <Tag description={"v26.5+"} />

The driver loads `/kubling-client-settings.properties` from the classpath by
default. Set `connectionPropsFilePath` in the JDBC URL when the settings are
stored in an external file.

<Callout type="warning">
  Kubling 26.5 no longer reads the previous `org.teiid.ssl.*` and
  `org.teiid.sockets.*` keys. Rename them to the `com.kubling.*` forms shown
  below. See the complete [26.5 naming
  migration](/naming-migration).
</Callout>
