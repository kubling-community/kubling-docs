# Go

New Go applications should use Kubling's
[official gRPC SDK](/clients/grpc/go). It manages Engine sessions and exposes
typed query results, statements and transactions without depending on
PostgreSQL compatibility.

```shell copy
go get github.com/kubling-community/kubling-grpc/sdk-go@latest
```

The [Go SDK guide](/clients/grpc/go) covers connection setup, queries,
statements, generated keys, transactions and TLS.

<Callout type="warning">
  An existing application can still use a PostgreSQL-compatible Go driver
  against an enabled `pgProtocol` listener. That transport is a compatibility
  surface and is not recommended for new Kubling applications.
</Callout>
